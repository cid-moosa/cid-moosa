### 🛰️ Bio & Mission
> **I thrive at the lowest layers of the stack.** From burning custom ESP32 firmware to reverse engineering USB OTG protocols and crafting high-performance Android Jetpack Compose interfaces. If it has signals, packets, or silicon, I build it, break it, and optimize it.

- 🔬 **Exploring**: RF signals, USB HID/Audio protocols, Wi-Fi 802.11 frame injection, and embedded microcontrollers.
- 🛠️ **Active Builds**: Hardware modification rigs, custom home servers, isolated networking stacks, and 3D printing custom enclosures.
- 🎯 **Philosophy**: *"Understand the machine from electrons to user interface."*
