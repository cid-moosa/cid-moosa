## Selected Work

| Project | Stack | Summary |
| :--- | :--- | :--- |
| [prodiscover](https://github.com/cid-moosa/prodiscover) | `Go` `Python` | 64-bit digital forensics suite combining a Go RAM/disk acquisition, MFT parser, and carver engine with a Tkinter GUI. |
| [ir-blaster](https://github.com/cid-moosa/ir-blaster) | `Kotlin` `Compose` | Native Android USB-C OTG IR transceiver supporting raw bulk endpoints, waveform visualization, and 100+ device profiles. |
| [grub-forge](https://github.com/cid-moosa/grub-forge) | `Python` `PyQt6` | Non-destructive Linux GRUB2 workstation with Btrfs/XFS discovery, Polkit separation, rescue scripts, and QEMU boot preview. |
| [esp32s3-nrf24-controller](https://github.com/cid-moosa/esp32s3-nrf24-controller) | `C++` `PlatformIO` | ESP32-S3-N16R8 firmware driving single or dual nRF24L01 radios over independent SPI buses with auto-probing and hardware triggers. |
| [labforge](https://github.com/cid-moosa/labforge) | `Python` `OOXML` | Automated `.docx` layout engine and agent skill resolving Word list/indent bugs, aligning screenshots, and compiling LibreOffice PDFs. |
